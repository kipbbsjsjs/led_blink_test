# led_blink_test — ESP32 非阻塞 LED 闪烁

毕业设计《基于 ESP32 的洗车工位喷淋控制系统》的基础 GPIO 测试程序。

## 功能

- 外接 LED 每 3 秒完成一次闪烁（亮 0.5 秒、灭 2.5 秒）
- 采用 `millis()` 非阻塞计时，与主项目"禁止 delay() 阻塞"的架构风格一致
- 串口同步打印亮灭状态（115200）

## 接线

| LED | ESP32 |
|-----|-------|
| 阳极（经 220Ω 限流电阻） | GPIO4（丝印 D4） |
| 阴极 | GND |

原理图：[LED闪烁实验.eprj2](LED闪烁实验.eprj2)（嘉立创EDA专业版工程文件，SQLite 格式）

## 使用

Arduino IDE（ESP32 板卡包）直接烧录即可，无第三方库依赖。
